# MotoWash Management System

Web platform developed for motorcycle wash business management.  
The system allows service organization, customer management, inventory control, and operational administration through a modern and responsive interface.

---

## Features

- User authentication system
- Customer management
- Service registration
- Inventory management
- Responsive interface
- Dashboard administration
- Database integration
- Modern UI design

---

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

### Database
- Sqlite

---
